## 🎯 Quick Start

```bash
git clone https://github.com/MTheUnexpected1/ComfyUI_Premium_Frontend.git
cd ComfyUI_Premium_Frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) - see the demo workflow in action!

## ✨ What Makes This Special

### Crystal-Clear Connections
- **16px ports** (2x larger than default)
- **4.5px edges** (thick, easy to trace)
- **Smooth curves** with professional Bézier paths
- **12 vibrant colors** for different data types
- **Hover highlighting** - see all connections at a glance

### 40+ ComfyUI Nodes
- Loaders, Samplers, VAE, ControlNet, LoRA
- Text encoding, image operations
- Full ComfyUI compatibility

### Modern UI
- Dark glassmorphic design
- Smooth animations
- Professional polish
